# English Beyond

Plataforma interativa de aperfeiçoamento de inglês para dois adultos, focada em viagens e conversação cotidiana.

## Conteúdo
- Diagnóstico individual com Reading, Grammar, Listening, Writing e Speaking.
- Trilha de 12 semanas com 60 sessões de 15–20 minutos.
- Correção automática das questões objetivas, prática oral com recursos do navegador e exercícios de escrita guiada.
- Revisão de conteúdos e acompanhamento individual.

## Como usar
Abra o site publicado, escolha **Diagnóstico**, crie seu perfil e realize as avaliações. Depois, acesse **Minha trilha** para começar as aulas.

## Publicação
O código principal está no arquivo `index.html`. Para disponibilizar o programa aos alunos, ative GitHub Pages em **Settings → Pages** e selecione o fluxo de publicação por **GitHub Actions**. O workflow `.github/workflows/pages.yml` faz a publicação após novas alterações na branch `main`.

Site previsto depois da ativação: https://victorfviana.github.io/english-beyond/

## Privacidade e limitações
Os dados e o progresso são salvos no armazenamento local do navegador. Não há sincronização automática entre dispositivos ou envio de resultados a um servidor. Use as opções de backup da plataforma antes de trocar de aparelho ou limpar os dados do navegador.

A classificação diagnóstica é pedagógica e não constitui certificação de nível CEFR. Exercícios de fala e escrita necessitam de feedback qualitativo adicional.
